# How we work

Fairly informal, with no rules beyond these:

- Each person works on their area's branch (`area/planner`, `area/llm-platform`, `area/data`) and in their own folder.
- `main` is what we submit. Open a PR when something is stable.
- Before starting: `git pull`.
- Do not push large maps or keys. Push the script that downloads them and record the source in `docs/DATA_SOURCES.md`.
- If you change a format shared between areas, update `docs/ARCHITECTURE.md` and let the group know.

If in doubt, ask in the group.
