# Product media

Images and videos used by the [main README](../../../README.md). Unlike the screenshot walkthrough in the parent folder, these were **recorded from the running application** (headless Chrome driven by Playwright, 1600 × 900, real GPU), against the deployed interface and its small language models.

| File | What it shows |
|---|---|
| `demo.mp4` | Product tour: mission → route → 3D route → layers → surface reconstruction (H.264, 1280 × 720, no audio) |
| `mission-to-route.mp4` / `.gif` | The Low battery mission sent to Bellona and the route appearing (waiting time cut) |
| `route-3d.mp4` / `.gif` | Transition to 3D, progressive route drawing, orbit |
| `layers.mp4` / `.gif` | Switching data layers (sped up 1.5×) |
| `surface.mp4` / `.gif` | Cheyava Falls reconstruction: look around, walk, orbit view |
| `route-*.jpg`, `layers-*.jpg`, `surface-*.jpg`, `map-overview.jpg`, `mobile-route.jpg` | Stills at full interface size (mobile at 390 × 844, 2×) |

Notes:

- The videos have no audio and the real model waiting time (about 20 s per mission) is cut out.
- Figures in the README text come from the interface panels in these captures.
- The layer and 3D-layer stills have several layers active at once, as the interface allows.
